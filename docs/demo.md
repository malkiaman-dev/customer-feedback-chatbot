# Short demonstration

1. Start the app and explain that the JSON file is the predefined knowledge base.
2. In FAQ preview, ask "Which technologies are required?" and expand Sources.
3. Open FAQ library, search README, then click Ask this question.
4. Ask "How old is the moon?" to demonstrate the no-match response.
5. Switch to AI answers, configure your API key, and repeat a supported question.
6. Explain the pipeline: question validation, keyword retrieval, context construction, Gemini response, source display.
7. Download the chat and click New conversation.
8. Open Project guide to explain usage and project details.
9. Demonstrate the same flow on the public deployment and submit both URLs.

The preview mode does not use an LLM. The AI demonstration requires a working key and available provider quota.
